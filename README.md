# Wine-Quality-Analysis Supervised Machine Learning Problem

## Project Overview
This project analyzes wine quality using data from the UCI Machine Learning Repository(classification) and Kaggle(regression). The objective is to predict and understand wine quality based on various physicochemical properties.

The project explores two machine learning approaches:

1. Classification (Completed)
2. Regression (In Progress)

## Dataset
Source: UCI Machine Learning Repository and Kaggle

The dataset contains physicochemical measurements of wine samples, including:
- Fixed Acidity
- Volatile Acidity
- Citric Acid
- Residual Sugar
- Chlorides
- Free Sulfur Dioxide
- Total Sulfur Dioxide
- Density
- pH
- Sulphates
- Alcohol
- Quality (Target Variable)

## Project Goals
- Identify factors influencing wine quality.
- Build predictive machine learning models.
- Compare classification and regression techniques.
- Generate insights from wine quality data.

## Classification Approach
### Objective
Predict wine quality categories based on physicochemical features.

### Workflow
1. Data Cleaning and Preprocessing - The data was clean from the source
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Data Scaling
5. Model Training
6. Model Evaluation

### Algorithms Used
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

### Key Findings
- Alcohol content showed a strong relationship with wine quality.
- Certain chemical properties contributed significantly to prediction performance.
- The classification model successfully distinguished between quality categories.
